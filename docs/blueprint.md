# **App Name**: NetPulse Home

## Core Features:

- Network Device Hub: An interactive dashboard visualizing active network infrastructure such as Routers, Extenders, and GPON units based on local IP configurations like 192.168.7.1.
- Smart Troubleshooting Tool: An AI-powered diagnostic tool that uses network status data to reason about connectivity issues and suggest precise optimization steps.
- Configuration Repository: Store and manage sensitive hardware details, including MAC addresses, firmware versions (like OpenWrt), and SSIDs in a secure database.
- Connectivity Watchdog: A real-time monitoring system that displays heartbeat status and simulated performance metrics for all managed nodes.
- Admin Portal Quick-Launch: Secure redirect links for quick access to manufacturer administration panels through dedicated 'Open' actions.
- Infrastructure Audit Log: Chronological tracking of network status changes and device information updates within a Cloud SQL instance.

## Style Guidelines:

- The primary color is a vibrant Cyan (#00D9FF), evoking a high-tech energy and precision contrast against the background.
- The background is a heavily desaturated, deep midnight navy (#050816) that provides a cinematic 'blackout' feel for neon accents to pop.
- The accent color is a rich Cobalt (#0051FF), which is an analogous shade used for primary action borders and structural gradients.
- A pairing of 'Space Grotesk' for technical headers and machine-like data readouts, with 'Inter' for crisp, objective body text.
- FontAwesome Solid icons with custom glow effects to symbolize network hardware, connection nodes, and security status.
- A futuristic grid system with glassmorphism cards and a repeating background pattern that simulates an electronic motherboard.
- Implementation of scrolling 'scanlines' and pulsing ambient glows for active devices to simulate a live digital monitor.
